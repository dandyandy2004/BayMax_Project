Baymax Version 0 is a healthcare companion robot inspired by Baymax from *Big Hero 6*. The goal of the project is to create a small and affordable robot that can help with basic healthcare needs when seeing a doctor or nurse isn't necessary or easily accessible.

The robot is designed for use in homes, classrooms, and school nurse offices. It focuses on monitoring basic health information and helping with everyday medical needs.

## Features

* ❤️ **Health Monitoring** – Measures basic health values such as temperature and pulse.
* 💊 **Medication Dispenser** – Dispenses specific amounts of medication at scheduled times.
* 🩹 **Bandage Dispenser** – Provides bandages for minor injuries.
* 🚨 **Emergency Support** – Future versions could help contact emergency services.
* 📊 **Health Tracking** – Future versions could store health information over time.

## Target Users

* Children
* Elderly individuals
* People who need regular health monitoring
* Schools and classrooms
* People with limited access to affordable healthcare
